# Correspondencia con el vocabulario del cliente

Versión 0.2 · Guía de traducción y definición por encargo

Conservar el lenguaje que el cliente necesita para decidir y operar. Acordar definición, unidad, periodo, población, fuente y uso antes de tratar dos términos como equivalentes. Esta tabla ofrece correspondencias de trabajo, no definiciones contables universales ni un catálogo obligatorio de métricas.

| Término del cliente | Dónde se construye | Definición y fundamento que deben acordarse |
|---|---|---|
| TAM | N03, universo de compra delimitado | Población, necesidad, unidad y gasto o volumen del periodo; distinguir una categoría estadística amplia de compradores pertinentes |
| SAM | N03/N08/N11, parte atendible bajo la oferta y condiciones | Filtros de geografía, compra, acceso y cumplimiento, con intersecciones sustentadas; no multiplicar porcentajes marginales como si fueran independientes |
| SOM | N06/N09–N12, parte que se pretende obtener | Requiere fundamento de acceso, elección y horizonte además de capacidad. La capacidad máxima propia es una restricción, no una estimación de cuota |
| ICP, fit o segmento prioritario | N04/N07 | Situación en que la oferta aporta valor y puede servirse, criterios observables de inclusión/exclusión y límites de transferencia |
| MQL, SAL, SQL u oportunidad | N09/N10 | Definir objeto, señal, criterio de admisión, receptor y próxima acción de cada estado. Conservar etiquetas existentes si representan estas condiciones |
| Scoring o cualificación | N10 | Cada variable tiene significado y fundamento; una condición indispensable se trata aparte de una suma compensatoria |
| Canal o motor de demanda | N09 | Lugar de acceso y mecanismo causal, población, actividad, señal, coste completo, receptor y condición de revisión |
| CAC | N09/N10/N12 | Coste completo atribuible a adquirir clientes nuevos dividido por clientes nuevos de población/ventana compatibles. Explicar reconocimiento y reparto; no sumarlo con sus partidas originales |
| Margen bruto / contribución | N11/N12 | Conciliar qué costes incluye cada magnitud. Una contribución metodológica no se renombra margen contable sin esa correspondencia |
| Payback | N12 | Primer momento en que el flujo acumulado definido recupera el desembolso pertinente. Indicar si se mide caja o contribución, cohortes y tratamiento del tiempo; un cociente estático exige un flujo estable defendible |
| LTV o valor de vida / LTV sobre CAC | N12 | Horizonte, supervivencia, contribución por periodo, costes iniciales y tasa cuando se use descuento. Conciliar unidades y perímetros antes del cociente; sin fundamentos no hay estimación defendible |
| DSO / DPO | N11/N12 | Precisar saldo y flujo compatibles, ventana, impuestos y criterio de promedio. Complementar con vencimientos por evento; una media no explica por sí sola cuándo habrá caja |
| MRR / ARR | N08/N11/N12 | Definir ingreso recurrente normalizado y tratamiento de altas, bajas, descuentos, uso y cargos únicos. Diferenciar importe contratado, reconocido y cobrado |
| NRR / GRR | N12/N13 | Definir cohorte inicial e ingreso recurrente comparable; expansión, contracción y bajas, sin incorporar nuevos clientes al denominador original. La identidad de cohortes es indispensable |
| Dashboard, CRM o automatización | N13/N15 | Definir campos, eventos, identidades, captura, responsable, permisos y decisión. Elegir después el medio que los representa |

Si la definición del cliente difiere, conservar ambas con su conciliación. Cuando una métrica no sea pertinente, registrar el motivo ligado a la decisión; no añadir recurrencia a una oferta que funciona de otra manera. Las fórmulas y variantes económicas vigentes gobiernan el cálculo; una etiqueta de esta tabla no implica que el libro automatice esa relación.
