# Plantilla de traspaso de contexto o medio

Versión 0.1 · Campos K02/K15/K17 pertinentes · Valores vacíos

Usar con [adaptación del entorno](../04_adaptacion_del_entorno.md) cuando se solicite un traslado real. No activar por cada conversación ni mantener un plan maestro de migración.

| Campo | Regla | Valor |
|---|---|---|
| Referencia | K/ sección/revisión, autor, fecha y ubicación del traspaso | |
| Motivo y tarea receptora | Resultado que necesita continuidad y razón del cambio de medio | |
| Ámbito autorizado | K01/DEC, contenido permitido, receptor y condiciones | |
| Origen y destino | Ubicaciones/entornos reales cuando exista prestación; permisos se verifican por destino | |
| Método necesario | Entrada, rutas e instrucciones sustantivas, versión y acceso | |
| Contenido seleccionado | Artefactos/campos, originales y revisiones necesarios; excluir lo ajeno a la tarea | |
| Tipo de disponibilidad | Archivo incluido, referencia accesible o dependencia no transferible | |
| Transformación | Exportación, extracción o conversión; original/localizador y pérdida material | |
| Decisión vigente | Compromiso, fundamento, límites y condición de revisión | |
| Pendiente y siguiente acción | Causa, responsable y contenido necesario para continuar | |
| Capacidad en destino | CAP, acción/entrada/salida y alternativa suficiente | |
| Estado recibido | Evidencia de contenido/acceso/recepción pertinentes; no inferir por envío | |
| Comprobación requerida | Criterio K14/K16 por capacidad; integridad distinta de uso o cálculo | |
| Edición e integración | Responsable, fuente autoritativa y revisión base para evitar sobrescritura | |
| Límite de transferencia | Fuente, fórmula, permiso o capacidad que no se conserva y efecto | |
| Cierre del traspaso | Localizadores actuales, disposición y continuidad; sin aprobación global de portabilidad | |

La síntesis de contexto no aumenta la evidencia. Conservar originales y resultados de comprobación con sus versiones y ámbito.
