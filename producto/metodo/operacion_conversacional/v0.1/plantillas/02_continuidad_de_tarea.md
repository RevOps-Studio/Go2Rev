# Plantilla de continuidad de tarea

Versión 0.1 · Campos agrupables de K02/K17 · Valores vacíos

Usar con [continuidad y cambios](../05_continuidad_y_cambios.md). Es una vista breve de localizadores y estado actual. No sustituye originales, contratos ni el registro de decisiones; no exige un nuevo documento si esos campos están disponibles.

| Campo | Regla | Valor |
|---|---|---|
| Referencia | K02/K17, sección/revisión, autor, fecha y ubicación | |
| Método y fuentes actuales | Versión de entrada y componentes pertinentes, con localizadores resolubles | |
| Ámbito y objetivo | K01/revisión y resultado que se está construyendo o revisando en la prestación | |
| Solicitud vigente | Petición actual, restricciones/correcciones y relación con tarea anterior | |
| Productor y consumidor | N/K, campo/revisión y uso E/O pertinente | |
| Decisión y autoridad | DEC, condición aceptada, parte habilitada y parte pendiente | |
| Trabajo completado | Resultado y fuente editable/localizador; no confundir redactado, guardado y recibido | |
| Originales materiales | AF/FUE y cobertura necesaria para continuar; resumen orientativo distinto de original | |
| Revisión base | Artefacto vigente, versión que sustentó decisión y vistas pendientes si las hay | |
| Carencia o contradicción | HUE/CON, causa, efecto, responsable y trabajo independiente permitido | |
| Cambio abierto | CAM y consumidores/disposiciones pendientes; no copiar todo el historial | |
| Operación interrumpida | Qué se confirmó, qué resultado es incierto y qué conciliar antes de repetir | |
| Capacidad pertinente | CAP/medio, permiso y limitación que afecta a la siguiente acción | |
| Siguiente acción | Trabajo concreto, entrada, salida y responsable; fundamento si requiere decisión | |
| Condición de cierre | Qué permite terminar la tarea y qué recepción sigue pendiente | |

La continuación recupera los originales necesarios desde estas referencias. Una nueva sesión no altera por sí sola decisiones, autoridad ni vigencia.
