# Trabajar con Go2Rev

Versión 0.3 · Entrada operativa

Go2Rev diseña y prepara un sistema comercial B2B con acompañamiento acotado. Atiende oferta existente en contexto nuevo (A) y nueva iniciativa (B), con prioridad inicial A. El encargo prevé desde la contratación el valor, recepción y tratamiento económico de cualquier salida de Diagnostic. Sus entregables tienen autonomía de RevOS y del proveedor de LLM.

## Arranque y continuación

1. Recuperar la versión del método, la petición y, si existe, el índice del encargo. Identificar resultado, receptor, autoridad y siguiente tarea vigente. Abrir N01 para encuadrar un encargo; continuar por la tarea registrada en los demás casos.
2. Leer esta entrada y los [invariantes](13_invariantes.md). La distribución reúne ambos y los criterios comunes en `CARGA_INICIO.md`; añadir la `CARGA_Nxx.md` pertinente, localizada en [rutas](02_rutas_y_lectura.md). Cada carga identifica qué contenido incorpora íntegro y qué queda fuera. Ese contenido metodológico incluido sustituye la apertura de sus originales; las fuentes de cliente y mercado se leen efectivamente para sostener el análisis.
3. Seguir los pasos y usar una copia de la plantilla vacía en el encargo. Abrir las secciones de extensión indicadas por sus condiciones, antes del cálculo, conclusión o compromiso dependiente. La lectura breve permite orientarse y comenzar; el tamaño de la carga no es un criterio de suficiencia del análisis.
4. Analizar lo disponible, producir conclusiones fundadas y solicitar solo aportaciones exclusivas necesarias. Usar la investigación externa para contrastar mercado, compra, alternativas y capacidades internas. Si falta material o acceso, localizar el hueco y avanzar lo independiente.
5. Guardar, comprobar que el contenido puede recuperarse y actualizar el índice. Informar resultado, ubicación, límite y siguiente acción. Si el entorno solo permite texto, entregar el contenido y declarar pendiente su guardado; la [guía de entorno](09_uso_por_entorno.md) resuelve alternativas de acceso y producción.

## Espacio persistente

Separar biblioteca del método y raíz del encargo. Usar `00 Sistema` para ámbito/índice; `01 Entregables` para Diagnostic, Design, Economia y Despliegue; `02 Anexos` para material del cliente, investigación externa y actas; `03 QA` para protocolos y observaciones; `04 Archivo` para sustituidos; `05 Operacion` para piezas de uso. Una estructura existente conserva sus rutas mediante correspondencia en el índice. Abrir [carpetas y guardado](08_carpetas_y_guardado.md) al crear el espacio o cambiar su organización. Mantener una fuente editable por contenido y vistas derivadas enlazadas.

## Vocabulario mínimo

| Código | Significado |
|---|---|
| N / K | Capacidad / contrato de entrada y salida |
| E / O | Exploración / uso operativo habilitado por acción y ámbito |
| FUE / AF | Fuente / afirmación con naturaleza y fundamento |
| HUE / SOL / CON | Carencia / solicitud selectiva / contradicción |
| TRA / CAP | Transferencia A / capacidad disponible o por habilitar |
| DEC / CAM | Decisión de autoridad / cambio y consumidores afectados |
| EVAL / CONTR / USO | Antes de evaluar / contratar / efectuar el uso dependiente |

El [glosario completo](00_glosario.md) y el diccionario amplían términos cuando se necesiten. El consultor trabaja con decisiones comprensibles; los códigos localizan el fundamento.
