# Plantilla de capacidad del entorno

Versión 0.1 · Campos CAP/K02 · Valores vacíos

Usar con [capacidades y alternativas](../03_capacidades_y_alternativas.md). Repetir solo para una acción material requerida por una tarea. Referenciar CAP existente si ya contiene los campos; no crear un inventario maestro paralelo ni completar esta plantilla con el entorno de desarrollo para probar la metodología.

| Campo | Regla | Valor |
|---|---|---|
| Referencia | CAP/K02, sección/revisión, autor, fecha y ubicación | |
| Tarea y ámbito | K01 y productor/consumidor; uso y compromiso que requiere la capacidad | |
| Acción necesaria | Leer, investigar, calcular, guardar, presentar o actuar; entrada y salida esperadas | |
| Medio disponible | Entorno, función expuesta, formato y límites pertinentes; sin inferir por marca | |
| Fuente de disponibilidad | Documentación/capacidad declarada o resultado previo; fecha y alcance | |
| Acceso y autorización | Acción, objeto/destino, contenido/ámbito y condiciones vigentes | |
| Disponibilidad efectiva | Estado CAP y evidencia; distinguir declaración, acceso y funcionamiento observado | |
| Cobertura | Contenido/campos/volumen/periodo, fidelidad, latencia y carencias | |
| Recepción exigida | Criterio metodológico que debe conservar la salida y quién la recibe | |
| Persistencia | Dónde queda resultado, cómo se recupera y qué confirma guardado | |
| Coste y mantenimiento | Condiciones conocidas o por verificar; efecto en K12/alcance | |
| Alternativa suficiente | Otro medio, transformación, esfuerzo y pérdida de capacidad si existe | |
| Límite dependiente | Qué conclusión/acción queda limitada y qué trabajo puede continuar | |
| Responsable | Propietario competente, ejecutor y receptor pertinentes | |
| Comprobación posterior | K14/K16 si se requiere; no declarar observación sin ejecución habilitada | |
| Cambio y vigencia | Condición que obliga a revisar capacidad/permiso y campos afectados | |

El registro de una capacidad no modifica la evidencia de mercado ni concede autoridad de negocio.


## Núcleo y ampliación

Conservar la identidad de tarea/encargo y método, capacidad o contenido pertinente, estado real, límite y siguiente acción. Completar la cabecera común una vez; abrir los bloques de migración, fallo o cambio solo si se activan. Un campo material desconocido conserva su efecto sobre el uso. Véase [núcleo y suficiencia](../12_nucleo_y_suficiencia.md).
