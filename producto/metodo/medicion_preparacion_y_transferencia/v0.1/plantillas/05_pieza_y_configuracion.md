# Plantilla de pieza, configuración y guía de tarea

Versión 0.1 · K15 · Campos empresariales vacíos

Usar con [materialización y uso](../04_materializacion_y_uso.md). Repetir por pieza/medio necesario; agrupar secciones cuando compartan una tarea. La fuente general no contiene materiales empresariales cumplimentados.

| Campo | Regla | Valor |
|---|---|---|
| Referencia | K15/sección/revisión, autor, fecha, ubicación y estado documental | |
| Obligación y uso | K01/K14, ámbito, destinatario y tarea que debe permitir | |
| Contexto humano | Iniciativa/recorrido de futura prestación, fase, naturaleza, motivo y decisión/tarea del lector | |
| Productores | K07–K13/campo/revisión, AF/FUE y límites del compromiso | |
| Material existente | Localizador/revisión, aptitud y qué se conserva/adapta; si falta, producción necesaria | |
| Medio elegido | Función, disponibilidad, alternativa, coste/mantenimiento y CAP | |
| Contenido operativo | Texto, campos, reglas o fórmulas completos para la tarea; sin trasladar redacción pendiente al usuario | |
| Variables y ausencias | Fuente de cada dato necesario, interpretación de desconocido y condición que impide avanzar | |
| Instrucción de entrada | Qué recuperar, dónde consultar/introducir y cómo reconocer la situación | |
| Acción y autoridad | Pasos, decisión, condición, ejecutor y compromiso permitido | |
| Excepción y ayuda | Qué hacer ante carencia, incompatibilidad o fallo; responsable y salida útil | |
| Registro y receptor | Qué guardar, ubicación, versión y qué acredita recepción/continuidad | |
| Fuente y vistas | Fuente editable autoritativa, derivados, precedencia y actualización | |
| Configuración necesaria | Origen/campo, transformación, destino, identidad/evento y criterio de recepción si procede | |
| Cambio autorizado | Ámbito, propietario, permiso, estado anterior y forma de recuperación cuando sea posible | |
| Configuración efectuada | Cambio, ejecutor/entorno, evidencia y revisión; separar especificado, aplicado y pendiente | |
| Conflicto de estados | Fuente competente, duplicidad, demora y conciliación antes de repetir compromisos | |
| Acceso de continuidad | Responsable y mecanismo autorizado, sin secretos dentro de la guía | |
| Criterio de revisión material | Fundamento, coherencia, unidades, legibilidad, guardado/lectura y límites | |
| Comprobación N16 | Protocolo/versión, entrada, operador/receptor y cobertura necesaria | |
| Carencias y consumo | HUE/CON, efecto, productor y disposición de recepción | |
| Cambio posterior | Condición CAM, fuente/vistas/configuración afectadas y observación que conservar/revisar | |

Describir una configuración no equivale a aplicarla. Completar una pieza no equivale a comprobar su uso. Conservar ambas condiciones en el traspaso a N16/N17.

## Aplicabilidad de los bloques

Antes de emitir K15, completar el núcleo de [N15 Producir piezas y configurar medios](../../../operacion_conversacional/v0.2/10_primera_pasada.md). Las reglas CONTR, EVAL, USO y de variante de esta plantilla mantienen su momento de exigibilidad. Un bloque condicional se completa cuando afecte al resultado; documentar la condición que lo hace aplicable o su exclusión. Una ausencia material queda localizada y limita el uso dependiente. La cabecera común se registra una vez por artefacto.
