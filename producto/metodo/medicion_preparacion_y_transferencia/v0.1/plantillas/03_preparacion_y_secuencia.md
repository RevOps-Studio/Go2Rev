# Plantilla de obligación, preparación y secuencia

Versión 0.1 · K14 · Campos empresariales vacíos

Usar con [preparación y secuencia](../02_preparacion_y_secuencia.md). Repetir por obligación/tarea pertinente dentro del encargo. La secuencia futura de prestación no constituye backlog del desarrollo de Go2Rev.

| Campo | Regla | Valor |
|---|---|---|
| Referencia | K14/sección/revisión, autor, fecha, ubicación y estado documental | |
| Encargo y ámbito | K01/revisión, destinatario, recorrido/variante y uso E/O | |
| Motivo de preparación | Obligación contratada, evidencia para decisión abierta o ambas; localizador | |
| Decisión habilitada | K06/DEC o pregunta exploratoria delimitada sin exigir K06 final | |
| Capacidad recibible | Qué debe poder hacerse, por quién y con qué condición de finalización | |
| Tarea y recorrido | Entrada, acción/decisión, salida, receptor y excepción material | |
| Contenido productor | K07–K13/campo/revisión y criterio admitido; carencias explícitas | |
| Pieza o medio | Función y localizador si existe; conservar, adaptar, producir o configurar | |
| Tipo de evidencia | Mercado/proceso, conducta comercial, cálculo/archivo, captura o uso; límite de conclusión | |
| Protocolo | Referencia a procedimiento y versión de criterio previo; qué cubrirá | |
| Dependencia de inicio | Productor, condición verificable y qué trabajo puede avanzar mientras falta | |
| Orden y prioridad | Precedencias, consecuencia de error, valor de información y coste de esperar/actuar | |
| Trabajo completo | Producción, preparación, ejecución, análisis, corrección y traspaso pertinentes | |
| Recurso y calendario | Competencia, CAP, disponibilidad neta y distribución temporal; asignación nominal distinta de efectiva | |
| Economía | Referencias de partidas/carga K12, ámbito, reconocimiento/pago y conciliación sin doble coste | |
| Acceso y autoridad | Permisos por acción, responsable y vigencia; no pedir de nuevo autoridad suficiente | |
| Condición de preparado | Entradas, versiones, personas, medios y observación efectivamente disponibles | |
| Límites | Gasto/esfuerzo/tiempo/exposición pertinentes y fundamento; desconocidos necesarios impiden esa ejecución | |
| Interrupción o ampliación | Condición de detener, responsable y autoridad para cambiar el compromiso | |
| Criterio de recepción | Obligación y evidencia necesaria; no exigir venta como cierre universal | |
| Alternativa o carencia | HUE/CON, efecto, opción suficiente y productor | |
| Acompañamiento | Trabajo del consultor/operador, soporte previsto y condición de fin conforme a K01 | |
| Consumidores y revisión | K15/K16/K17 o N06, campo/revisión, disposición y CAM pertinente | |

El [protocolo previo](04_protocolo_previo.md) desarrolla la actuación cuando proceda. Identificar una pieza en esta tabla no significa que esté materializada ni comprobada.
