# Plantilla de protocolo previo

Versión 0.1 · Sección K14 · Campos empresariales vacíos

Usar con [obtención de evidencia](../03_protocolos_de_evidencia.md) o [comprobación de preparación](../05_comprobacion_de_preparacion.md), según la pregunta. El protocolo debe incorporar el procedimiento pertinente y su adaptación de alcance; escribir solo su nombre no lo completa. Su ejecución es posterior a la construcción íntegra del método.

| Campo | Regla | Valor |
|---|---|---|
| Referencia y estado | K14/sección/revisión, autor, fecha, ubicación y estado documental | |
| Encargo y obligación | K01/revisión y compromiso o pregunta que justifica la actuación | |
| Proposición y consumidor | AF/HUE, decisión, productor/campo/revisión que necesita la evidencia | |
| Explicación alternativa | Qué otra lectura debe poder distinguirse y por qué importa | |
| Tipo de evidencia | Selección razonada entre fuentes/proceso, conducta comercial, funcionamiento o uso | |
| Cobertura y límite | Qué podrá concluirse, qué no y qué variantes/condiciones se observarán | |
| Población y unidad | Inclusión/exclusión, identidad, selección, sesgos y representatividad que puede sostenerse | |
| Versiones | Oferta/ruta/material/regla, fuente editable y medio/entorno pertinentes | |
| Entradas | Origen, localizador, condición conocida/desconocida y autorización de uso | |
| Recursos efectivos | Ejecutor, operador/receptor cuando procedan, competencia, disponibilidad y respaldo | |
| Permisos | Acceso, contacto, registro, exposición, gasto o modificación según actuación | |
| Instrucción al ejecutor | Contexto, propósito, tarea, guía y apoyos normales; sin transferir análisis pendiente | |
| Procedimiento | Secuencia concreta, responsables, entrada/salida y condiciones de cada paso | |
| Criterio previo | Evidencia/resultados que permitirán discriminar la pregunta o evaluar cumplimiento | |
| Condición contraria | Qué refutaría la premisa o impediría el compromiso dependiente | |
| Tratamiento de inconclusión | Ausencia de captura, condición no observada, desconocido y no respuesta separados | |
| Magnitudes y tolerancia | Definición K12/K13, unidades, dominio y precisión/criterio sustentados cuando procedan | |
| Tiempo de observación | Origen/corte/ventana y madurez; sin interpretar prematuramente un resultado | |
| Comparación | Asignación/condiciones de alternativas cuando proceda, posibles diferencias y límite causal | |
| Rastro previsto | Original, fecha/contexto, acciones, ayudas, resultados, coste/carga y lugar de conservación | |
| Preparabilidad | Evidencia de disponibilidad de entradas, medios, personas y captura; dependencias aún pendientes | |
| Límites y detención | Recursos/compromisos autorizados, condición de interrupción y responsable | |
| Corrección y repetición | Causa/cambio que justificarían repetir, cobertura afectada y límite acordado | |
| Salidas de decisión | Qué hacer ante respaldo, contradicción, fallo o evidencia insuficiente; autoridad | |
| Revisión y consumo | Productor receptor, campo/revisión, disposición y condición CAM antes de actuar | |

Fijar estos criterios antes de la observación. La [plantilla de observación](06_observacion_y_correccion.md) conservará después el resultado sin modificar el protocolo retrospectivamente.
