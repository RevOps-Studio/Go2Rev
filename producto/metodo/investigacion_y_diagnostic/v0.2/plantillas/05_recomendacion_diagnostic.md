# Plantilla · K06 Recomendación Diagnostic

Versión de plantilla 0.2 · Campos de prestación vacíos

Usar con [N06](../05_recomendacion_diagnostic.md) y el [contrato exploratorio](../06_contratos_y_economia_exploratoria.md). El asistente redacta, el consultor revisa y el patrocinador decide el compromiso. K06 muestra propuesta y fundamento; DEC conserva la disposición efectiva sin duplicarla como evidencia.

La cabecera común identifica K06, revisión, autor/fecha, K01, ámbito, entradas, estado y ubicación. Los campos materiales se requieren para la decisión concreta; una dimensión no examinada se declara con su efecto y con las obligaciones de K01 que sigan pendientes. Las columnas Valor están vacías en el producto.

## Decisión que se presenta

| Campo | Regla | Valor |
|---|---|---|
| Pregunta y compromiso | Qué se decide y qué trabajo se habilitaría; alcance y reversibilidad | |
| Mandato, límites y autoridad | K01/revisión, condición económica de salida y responsable competente | |
| Recomendación principal | Salida propuesta, combinación y motivo central; no atribuye aceptación | |
| Aporte de Diagnostic | Qué conocimiento modifica o fundamenta la lectura inicial de K02 | |
| Síntesis del contraste externo e interno | Lectura inicial, evidencia externa, concordancias/tensiones, condiciones o alternativas y consecuencias; referencia a la plantilla de contraste integrada | |
| Cobertura efectiva | Dimensiones examinadas, entradas recibidas y límites de las no examinadas | |
| Suficiencia externa para la recomendación | Qué fuentes y cruces sustentan las conclusiones; carencia material y alcance parcial cuando no se complete la lectura pertinente | |

## Opción o combinación · Bloque repetible para alternativas materiales

| Campo | Regla | Valor |
|---|---|---|
| Identidad y perímetro | Sección estable de K06; qué se mantiene y qué cambia frente a otras opciones | |
| Segmento, situación y alternativas | K03/K04/K05 y versiones de campos pertinentes | |
| Oferta, unidad y condiciones | K08 E con alcance, precio/hipótesis y límites | |
| Acceso y proceso de compra | K09/K10 E, mecanismo, permisos, trabajo y respuesta conocida o desconocida | |
| Entrega, cobro y recursos | K11 E, CAP/TRA y condiciones de cumplimiento | |
| Economía recibida | K12 E, ubicación del modelo, unidad/periodo, resultados calculables y no calculables | |
| Tesis causal | Necesidad/alternativa → oferta → acceso/compra → entrega/cobro → economía/recursos; fundamento por enlace | |
| Restricciones | Incompatibilidad conocida, carencia de conocimiento o riesgo delimitable; efecto por compromiso | |
| Mejor argumento contrario | Alternativa explicativa y evidencia que podría hacer preferible otra opción | |
| Premisa y variación decisivas | Qué podría invertir la recomendación y qué fundamento tiene ese análisis | |
| Dinámica y horizonte | Cambio/tendencia material, mecanismo, desfase y límite de su efecto sobre la combinación, cuando proceda | |
| Consecuencia y uso admisible | Qué permite y qué permanece detenido o desconocido | |

La opción pertinente de mantener situación, no invertir o aplazar se describe con los campos que le apliquen, justificando los demás. Una combinación coherente no toma valores favorables de opciones incompatibles.

## Salida y consecuencias

| Campo | Regla | Valor |
|---|---|---|
| Salida recomendada | Continuar, continuar con condiciones, obtener evidencia adicional, ajustar, aplazar o cerrar | |
| Alcance permitido y parte detenida | Acciones/entregas precisas y dependencias; obligatorio si hay condiciones | |
| Condiciones pendientes | Evidencia de cumplimiento, responsable, recurso y evento límite | |
| Evidencia adicional | Pregunta, contexto, explicación alternativa, criterio previo, acceso, ejecutor, exposición, permiso y parada; N14 desarrolla protocolo si se necesita actuación | |
| Ajuste de encargo | Campo de K01, nueva propuesta de alcance/condiciones y autoridad requerida, cuando proceda | |
| Evaluación recibible | Contenido que se entrega aun si no continúa la construcción; cobertura y límites | |
| Economía de la salida | Referencia a regla acordada de K01, obligaciones de trabajo no ejecutado y recepción/liquidación | |
| Aplazamiento o terminación | Qué cesa o permanece, continuidad y condición de reapertura según salida | |
