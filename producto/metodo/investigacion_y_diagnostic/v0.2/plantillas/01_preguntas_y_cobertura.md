# Plantilla · Preguntas, cobertura y suficiencia

Versión de plantilla 0.2 · Campos de prestación vacíos

Usar con [investigación común](../01_investigacion_y_suficiencia.md). El asistente redacta cada bloque para una pregunta material y el consultor revisa su conclusión. Integrarlo en el K consumidor o referenciarlo desde él. FUE, AF, HUE, SOL y CON se mantienen en el registro compartido de FND02.

Todos los campos que justifican el uso indicado son obligatorios antes de cerrar la pregunta. Durante una prestación, los desconocidos y no aplicables se declaran con su motivo. Las reglas de estas tablas son metadatos; la columna Valor permanece vacía en el producto.

## Encuadre de pregunta · Bloque repetible

| Campo | Regla | Valor |
|---|---|---|
| Identidad y revisión | K consumidor y sección estable, autor y fecha | |
| Ámbito y entrada | K01/K02 y revisiones, recorrido A/B, geografía/segmento y periodo pertinentes | |
| Decisión y compromiso | Qué elección necesita informarse y qué acción podría habilitar | |
| Pregunta y alternativas | Proposición que distingue opciones; incluir permanecer o no invertir cuando corresponda | |
| Premisa examinada | Qué se toma como dado y por qué podría cambiar la decisión | |
| Conocimiento inicial | AF/FUE/TRA/CAP ya disponibles; qué falta sin repetir peticiones | |
| Prioridad y límite de esfuerzo | Consecuencia, reversibilidad, dependencia y momento del compromiso | |
| Evidencia adecuada | Tipo de original o conducta pertinente a la proposición y alcance necesario | |
| Disponibilidad y alternativa | Acceso/lectura reales, permisos y vía alternativa; capacidad ausente no se presume disponible | |
| Responsable de obtención/análisis | Asistente o responsable exclusivo del hecho; SOL cuando corresponda | |

## Exploración y profundización

### Propuesta de fuente o acceso · Bloque condicional y repetible

Usar la [rutina breve](../09_rutina_de_fuentes_y_acceso.md) al necesitar cobertura o acceso adicional. El asistente concreta la propuesta durante la prestación; la tabla permanece vacía en el producto. Incorporar una fuente al conjunto de investigación no equivale a conectar un servicio ni a haber leído su contenido.

| Campo | Regla | Valor |
|---|---|---|
| Necesidad y dimensión | Pregunta, campo consumidor y carencia que justifica la propuesta | |
| Candidata y ubicación | Nombre concreto de fuente, herramienta o lugar y URL/localizador verificado, o pendiente explícito | |
| Aportación diferencial | Qué información permite obtener o analizar y por qué mejora el acceso/cobertura actuales | |
| Cobertura, método y vigencia | Ámbito, periodo, origen, limitaciones y fecha de verificación; no suponer independencia por ser externa | |
| Acceso propuesto y disponibilidad | Web, archivo, exportación, herramienta o MCP; qué está disponible, conectado y autorizado realmente | |
| Condición de coste o permiso | Coste conocido o por verificar, autorización necesaria y alcance del acceso | |
| Recomendación y alternativa | Incorporar al conjunto, obtener exportación, proponer conexión o posponer; alternativa suficiente mientras tanto | |
| Disposición y rastro | Decisión vigente, responsable/fecha, FUE al identificar el material y SOL si se requiere obtención; conservar lo ya decidido | |

### Investigación realizada durante la prestación

| Campo | Regla | Valor |
|---|---|---|
| Cobertura de exploración | Familias, ámbitos, términos decisivos, fechas y límites; registro suficiente para entender exclusiones | |
| Factores descubiertos | AF con fuente o hipótesis nueva; qué cambia frente al punto de partida | |
| Cobertura externa pertinente | Mercado, competidores, producto/solución, compra, tendencias, acceso y condiciones; analizada, limitada o no pertinente con motivo | |
| Profundización seleccionada | Incógnita que puede invertir o impedir el compromiso y razón de priorizarla | |
| Fuentes examinadas | FUE/revisión/localizador y cobertura leída; sin duplicar su ficha | |
| Dependencia entre fuentes | Grupos de origen y límites de corroboración independiente | |
| Evidencia contraria | AF/FUE, explicación alternativa y resultado del contraste | |
| Sesgos y comparabilidad | Selección, cobertura, población, fecha, unidad y transformaciones relevantes | |
| Contradicciones y carencias | CON/HUE, efecto y vía de resolución | |

## Conclusión y cierre de búsqueda

| Campo | Regla | Valor |
|---|---|---|
| Conclusión y razonamiento | AF de conclusión, premisas, relación causal o derivación y alternativas | |
| Aporte a la decisión | Qué cambia, confirma con nuevo fundamento o limita respecto de K02 | |
| Cruce externo e interno | Premisas/AF, comparabilidad, conclusión y campo afectado; sección de contraste sin duplicar registros | |
| Juicio de suficiencia por uso | Pertinencia, calidad, independencia, actualidad y coherencia; E/O y compromiso concreto | |
| Motivo de cierre de búsqueda | Suficiente para ese uso, requiere otro tipo de evidencia o límite de alcance/recursos; explicar consecuencia | |
| Uso permitido y conclusión excluida | Campos admisibles y lo que la cobertura no sostiene | |
| Evidencia adicional necesaria | SOL o encargo a N14 con proposición, contexto, criterio, exposición, responsable, permiso y parada; si procede | |
| Revisor y fecha | Autoría y alcance de revisión; no atribuir revisión independiente si no existe | |
| Consumidores y reapertura | K/campos y versiones; nueva evidencia o cambio que obliga a reconsiderar | |
