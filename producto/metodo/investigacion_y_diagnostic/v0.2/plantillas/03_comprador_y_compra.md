# Plantilla · K04 Comprador y compra

Versión de plantilla 0.2 · Campos de prestación vacíos

Usar con [N04](../03_comprador_y_compra.md). El asistente produce el análisis y la propuesta; el consultor revisa; el patrocinador decide foco mediante DEC. La cabecera común identifica K04, revisión, autor, fecha, K01, ámbito, entradas, estado y ubicación conforme a los [contratos](../06_contratos_y_economia_exploratoria.md).

Repetir bloques solo para segmentos, funciones y transiciones pertinentes. Una hipótesis específica permite explorar; afirmar preferencia, conducta o autoridad exige su fundamento. Las columnas Valor permanecen vacías.

## Segmento y situación · Bloque repetible

| Campo | Regla | Valor |
|---|---|---|
| Segmento y ámbito | Situación/grupo delimitado, geografía y periodo, dentro de K01/K03 | |
| Inclusión, exclusión y solapamiento | Condiciones observables que distinguen el grupo y cómo se asigna una unidad | |
| Trabajo y problema | Actividad afectada, quién recibe la consecuencia y soporte AF | |
| Desencadenante y momento | Qué haría revisar la solución actual; distinguir declarado, observado e inferido | |
| Alternativa actual | Cómo se resuelve o se mantiene la situación; fundamento o hipótesis | |
| Consecuencia de seguir igual | Coste, riesgo o efecto conocido/desconocido; no presumir urgencia | |
| Restricciones de compra/adopción | Presupuesto, admisión, calendario, riesgo, integración y continuidad pertinentes | |
| Evidencia y cobertura | AF/FUE, población/contexto, sesgo y límite de generalización | |
| Contraste de compra externo e interno | Necesidad/criterio/rol interno frente a evidencia externa, comparabilidad, dimensión nueva e implicación sobre segmento/oferta | |
| A/B y capacidad de servir | TRA/CAP y condición que debe sostener la oferta en ese segmento | |

## Función en la compra · Bloque repetible

| Campo | Regla | Valor |
|---|---|---|
| Función y ámbito | Uso, prescripción, evaluación, aprobación, contratación, pago o aceptación; intermediario/final si procede | |
| Decisión y autoridad | Qué decide o bloquea; evidencia o desconocimiento de su autoridad | |
| Criterio e interés | Qué necesita conseguir/proteger en esa situación; atribución y soporte | |
| Información/evidencia requerida | Qué permite juzgar admisibilidad o preferencia | |
| Relación con otras funciones | Dependencia, conflicto o acumulación de roles; sin asignar por estereotipo de cargo | |

## Transición de compra · Bloque repetible

| Campo | Regla | Valor |
|---|---|---|
| Situación de entrada | Estado o evento de comprador y naturaleza de su conocimiento | |
| Decisión a resolver | Qué necesita decidir para avanzar o elegir otra salida | |
| Responsable de decisión | Función y autoridad de la sección anterior | |
| Condición y evidencia de avance | Evento/criterio observable; acción del vendedor separada | |
| Otras salidas y fricciones | Pausa, retorno, abandono o permanencia, y causas sustentadas o hipotéticas | |
| Tiempo y eventos | Inicio/fin, unidad, periodo y cobertura; desconocido si no hay sustento | |
| Requisitos para N10/N11 | Trabajo comercial, condición de inicio/aceptación y límites que deben respetar | |

## Comparación y foco recomendado

| Campo | Regla | Valor |
|---|---|---|
| Criterios decisivos | Necesidad, acceso, compra, servicio, economía y evidencia; explicar pertinencia | |
| Restricciones por opción | Incompatibilidades conocidas, capacidades por habilitar y carencias | |
| Comparación razonada | Ventajas, renuncias y relaciones entre criterios; no compensar imposibilidades con puntuación | |
| Foco propuesto y fundamento | A quién empezar, por qué y mejor alternativa descartada para ese uso | |
| Condición que cambia la prioridad | Premisa decisiva y evidencia que la resolvería | |
| Suficiencia y evidencia pendiente | AF/HUE/CON, uso exploratorio o compromiso delimitado; solicitud a N14 si corresponde | |
| Consumidores | Campos/versiones para N05–N11 y N13; N06 integra la elección | |
| Revisión y disposición | Consultor/fecha, DEC cuando exista, límites y disparadores de CAM | |
