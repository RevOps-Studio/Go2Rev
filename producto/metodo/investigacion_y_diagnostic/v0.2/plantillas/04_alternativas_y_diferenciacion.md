# Plantilla · K05 Alternativas y diferenciación

Versión de plantilla 0.2 · Campos de prestación vacíos

Usar con [N05](../04_alternativas_y_diferenciacion.md). El asistente compara, el consultor revisa y N06/N07 consumen las hipótesis sin convertirlas en decisiones aceptadas. La cabecera común de K05 conserva revisión, autor/fecha, K01, ámbito, entradas, estado y ubicación según [contratos](../06_contratos_y_economia_exploratoria.md).

El universo se delimita por la decisión; no se exige número fijo de alternativas o hipótesis. Repetir los bloques pertinentes y referenciar AF/FUE de FND02. Los valores permanecen vacíos.

## Universo y comparación

| Campo | Regla | Valor |
|---|---|---|
| Trabajo, situación y comprador | K03/K04 y versiones; define qué opciones son comparables | |
| Familias de alternativa consideradas | Ofertas directas, otras categorías, solución interna y permanencia según pertinencia | |
| Inclusión/exclusión y cobertura | Criterios, ámbitos y fuentes examinadas; límites de lo no localizado | |
| Prioridad de profundidad | Qué alternativas pueden cambiar la decisión y por qué | |
| Criterios comunes | Admisibilidad, elección y entrega pertinentes a K04; no seleccionar solo atributos favorables | |
| Unidad y alcance comparable | Trabajo, resultado, periodo, condiciones y cobertura; diferencias que impiden equivalencia | |

## Alternativa · Bloque repetible

| Campo | Regla | Valor |
|---|---|---|
| Identificación y pertinencia | Opción efectivamente investigada o familia hipotética identificada como tal; relación con trabajo del comprador | |
| Oferente, solución y disponibilidad | Entidad, producto/servicio, versión/estado, segmento/ámbito y relación entre marcas; anuncio distinto de disponibilidad o resultado | |
| Mecanismo, promesa y destinatario | Qué resuelve, cómo y para quién; distinguir publicado, documentado e inferido | |
| Evidencia disponible y límite | AF/FUE, fecha, localizador, cobertura y naturaleza de cada conclusión material | |
| Requisitos de adopción/entrega | Recursos, integración, aceptación, continuidad y obligaciones pertinentes | |
| Funcionamiento y evolución | Capacidades/restricciones documentadas, cambios de producto o actuación competitiva con fecha, fundamento y efecto en la elección | |
| Precio y condiciones conocidos | Unidad, moneda, impuestos, fecha, alcance y mínimos; desconocidos explícitos | |
| Coste completo pertinente | Preparación, adopción, uso, continuidad y salida; cobertura y carencias, sin doble imputación | |
| Criterios de comparación | Qué cumple, qué cambia y su consecuencia para K04; características técnicas cuando sean decisivas | |
| Fricción de cambiar o permanecer | Esfuerzo, riesgo, dependencia, reversibilidad y desencadenante; AF o hipótesis | |
| Argumento favorable y contrario | Razones sustentadas por las que puede ser elegida o descartada para esa situación | |

## Hipótesis de diferencia · Bloque repetible cuando exista fundamento

| Campo | Regla | Valor |
|---|---|---|
| Diferencia y comparación | Qué cambia, frente a qué alternativa, para qué comprador y condición | |
| Mecanismo y premisas | AF/TRA/CAP, razón causal y límites; no confundir formulación verbal con capacidad | |
| Relevancia para compra | Criterio/rol de K04 y evidencia o hipótesis que la sustenta | |
| Distinción dentro de cobertura | Qué alternativa podría ocupar el mismo espacio bajo otra forma o lenguaje | |
| Capacidad de sostener | Recursos, entrega, economía y respaldo propios, existentes o por habilitar | |
| Razón para adoptar | Beneficio/condición frente a fricción de cambio y alternativa actual | |
| Mejor explicación contraria | Por qué la diferencia podría no importar, no ser sostenible o no justificar compra | |
| Refutación y evidencia necesaria | Proposición/condición que cambiaría la conclusión; HUE/SOL o petición a N14 | |
| Uso propuesto y límites | N06/N07/N08/N09/N10; qué puede diseñarse y qué no puede afirmarse | |

## Síntesis y recepción

| Campo | Regla | Valor |
|---|---|---|
| Comparación y propuesta | Hipótesis que merece desarrollo, ajuste o descarte y fundamento; puede no existir diferencia favorable defendible | |
| Efectos conectados | Comprador, oferta, unidad, acceso, capacidad y economía que deben revisarse | |
| Contraste con oferta y capacidades propias | Premisas de K02, hallazgos externos, comparabilidad, conclusión y decisión que cambia o se fundamenta | |
| Suficiencia y carencias | Cobertura de alternativas materiales, comparabilidad, CON/HUE y límite de uso | |
| Consumidores y revisión | Campos/versiones, autoría de revisión y disparador de cambio de alternativa/criterio/capacidad | |
