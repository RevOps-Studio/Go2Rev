## Cruce material · Bloque repetible

Los campos que sostienen una conclusión material son obligatorios para ese uso. Una ausencia o falta de comparabilidad se explica, con HUE si requiere resolución. La columna Valor permanece vacía en la fuente del producto.

| Campo | Regla | Valor |
|---|---|---|
| Identidad y decisión | K productor/sección/revisión, autor, fecha y compromiso consumidor | |
| Premisa interna | AF/K02 y revisión con su naturaleza; objetivo como declaración/mandato y capacidad con su soporte, sin crear nuevas naturalezas | |
| Dimensión interna nueva | Campo afectado que el cliente no contemplaba, si no hay premisa previa; no inventarla | |
| Proposición externa | AF/FUE, versión, localizador, ámbito, fecha y naturaleza | |
| Origen e independencia | Autor y grupo de origen de ambas perspectivas; dependencia o patrocinio material | |
| Comparabilidad | Situación, comprador, geografía, periodo, unidad y alcance; transformación o límite de transferencia | |
| Relación encontrada | Concordancia, tensión, condición de encaje, capacidad por habilitar, alternativa nueva, contexto o indeterminación; explicar significado | |
| Razonamiento y mecanismo | Cómo se llega desde las premisas a la consecuencia, con alternativas explicativas | |
| Evidencia contraria y límite | Qué debilita la conclusión y qué no puede afirmarse | |
| Conclusión derivada | AF que conserva las premisas y el uso; no reescribir el original del cliente | |
| Recomendación y efectos | Qué mantener, adaptar, descartar u obtener; impacto en comprador, promesa, acceso, entrega, economía o momento | |
| Requisito o capacidad pendiente | TRA/CAP/HUE/SOL, responsable y momento necesario, cuando corresponda | |
| Campo y versión receptores | K03–K06/K08–K12 u otro consumidor pertinente; disposición por uso E/O | |
| Autoridad y revisión | DEC si se comprometen recursos/alcance; revisor, condición de refutación y CAM si cambia lo consumido | |

## Cambio o tendencia material · Bloque condicional

| Campo | Regla | Valor |
|---|---|---|
| Cambio y ámbito | Variable/dirección, población o producto/solución, periodo y horizonte | |
| Naturaleza temporal | Cambio observado, señal inicial, anuncio o previsión, con AF/FUE | |
| Base y método | Fecha del hecho y de publicación, cobertura, comparabilidad temporal y dependencia entre fuentes | |
| Mecanismo e implicación propia | Cambio externo → compra/requisito afectado → efecto en oferta/acceso/entrega/economía → decisión | |

| Acción y revisión | Decisión actual o contexto, evento/evidencia que justificaría revisar; sin ampliar soporte contratado | |
