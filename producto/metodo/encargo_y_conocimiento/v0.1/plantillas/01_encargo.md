# Plantilla · Encargo K01

Versión de plantilla 0.1 · Campos de prestación vacíos

Usar con [N01](../01_encargo_y_salida.md) y el [diccionario común](../03_contratos_y_diccionario.md). La columna Regla es metadato metodológico. La columna Valor se completa únicamente durante una futura prestación. Repetir los bloques indicados cuando proceda; no crear filas sin finalidad.

**Obligatoriedad:** EVAL = antes de iniciar la evaluación contratada; CONTR = antes de contratar; USO = antes del uso dependiente; A/B = condicional al recorrido. Un campo puede estar pendiente mientras se redacta la propuesta; registrar su efecto. Todo compromiso material necesita fuente/localizador o DEC. La aceptación se registra exclusivamente en DEC.

## Consecuencias previstas · Todas las salidas admisibles antes de contratar

Los nombres de salida son opciones del método, no decisiones de la prestación. Cada celda de contenido permanece vacía. Las reglas comunes pueden referenciarse por localizador inequívoco.

| Salida admisible | Trabajo que sigue o termina | Condición, responsable y autoridad | Tratamiento económico y referencia | Recepción, continuidad y reapertura |
|---|---|---|---|---|
| Continuar | | | | |
| Continuar con condiciones | | | | |
| Obtener evidencia adicional | | | | |
| Ajustar | | | | |
| Aplazar | | | | |
| Cerrar | | | | |

Para condiciones, identificar trabajo permitido y compromiso detenido. Para evidencia adicional, precisar pregunta, actuación, recursos, permisos y criterio de decisión. Para ajuste, determinar qué cabe en el encargo y qué requiere modificarlo. Para aplazamiento, identificar vigencia y obligaciones que persisten. Para cierre, identificar entrega y finalización.
