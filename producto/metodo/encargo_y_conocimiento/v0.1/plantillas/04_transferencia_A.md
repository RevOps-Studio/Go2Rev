# Plantilla · Transferencia de oferta a contexto nuevo

Versión de plantilla 0.1 · Recorrido A · Campos de prestación vacíos

Usar con [N02, recorrido A](../02_conocimiento_y_solicitud.md). Repetir el bloque por elemento material que se pretenda trasladar. El analista produce la comparación y el consultor revisa la inferencia. Los datos conservan su AF, ámbito y revisión; esta matriz no duplica el registro de afirmaciones.

La cobertura considera necesidad, situación y roles de compra, alternativas, acceso, promesa/precio, entrega/cobro y recursos. Seleccionar únicamente los elementos que puedan cambiar la decisión siguiente. Una condición desconocida en destino permanece desconocida.

## Identidad y elemento · Requerido en cada TRA

| Campo | Regla | Valor |
|---|---|---|
| ID, revisión, autor y fecha | Identidad estable TRA y contenido | |
| Encargo y conocimiento | K01/K02 y revisiones pertinentes | |
| Elemento que se pretende trasladar | Capacidad, material, mecanismo, condición o resultado; precisar cuál | |
| Decisión y consumidor | Nodo/campo que necesita juzgar su transferencia | |
| Contexto de origen | Geografía, segmento, compra, canal, unidad y periodo pertinentes | |
| Evidencia en origen | AF/FUE y revisiones; distinguir resultado documentado y explicación causal | |
| Mecanismo propuesto | Por qué podría funcionar y qué condiciones necesita; AF de inferencia/hipótesis si corresponde | |
| Contexto de destino | Ámbito acotado por K01; diferencias conocidas y preguntas abiertas | |

## Comparación · Bloque repetible por condición habilitante

| Campo | Regla | Valor |
|---|---|---|
| Condición de origen | Factor necesario o facilitador y por qué; fundamento AF o hipótesis identificada | |
| Estado en destino | Equivalente con soporte, diferente con soporte o desconocido; describir condición concreta | |
| Fundamento de destino | AF/FUE y ámbito; HUE si no se conoce | |
| Efecto sobre el mecanismo | Qué se mantiene, cambia o no puede determinarse; razonamiento | |
| Adaptación necesaria | Cambio de oferta, acceso, entrega u otro elemento; condición y dependencia, sin atribuir ejecución | |
| Evidencia de destino necesaria | Proposición que debe resolverse y tipo de fuente pertinente; SOL o protocolo de futura prestación | |
| Responsable y momento | Nodo/persona que obtiene o decide, recurso y evento que limita el compromiso | |

## Conclusión de transferencia · Requerido antes de consumir TRA

| Campo | Regla | Valor |
|---|---|---|
| Inferencia permitida | Qué se puede reutilizar, adaptar o conservar como pregunta y por qué | |
| Límite de transferencia | Lo que no sostiene la evidencia de origen, incluida respuesta de destino cuando no esté acreditada | |
| Uso y suficiencia | E/O, decisión consumidora y por qué las condiciones bastan o no para ese uso | |
| Alternativa y compromiso detenido | Opción si no puede transferirse; dependencia pendiente cuando corresponda | |
| Revisión del consultor | Autor, fecha y alcance; no equivale a resultado en destino | |
| Disparador de cambio | Condición, diferencia o evidencia nueva que reabre TRA y sus consumidores | |
