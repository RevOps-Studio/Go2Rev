# Plantilla de posicionamiento y elección de marco

Versión 0.1 · K07 · Campos empresariales vacíos

Usar con [posicionamiento y promesas](../01_posicionamiento_y_promesas.md). Repetir los bloques de alternativa y conclusión solo cuando la decisión lo requiera. Son secciones de K07, no registros ni planes maestros adicionales. Aplicar el [diccionario común](../../../encargo_y_conocimiento/v0.1/03_contratos_y_diccionario.md): en una prestación, desconocido, no aplica y cero tienen significados distintos.

## Marco candidato — bloque repetible

| Campo | Regla | Valor |
|---|---|---|
| Localización del candidato | Sección estable dentro de K07; descripción comprensible | |
| Marco de referencia | Categoría/subcategoría/combinación o marco nuevo y motivo para considerarlo | |
| Comparación inducida | Alternativas y criterios que el comprador tendería a usar; AF que sostiene la inferencia | |
| Promesa | Beneficio, mecanismo, compromiso controlable y condiciones | |
| Razones para creer | Requisito básico, característica, capacidad, evidencia de resultado o preferencia; no exigir que todas diferencien | |
| Afirmaciones internas | AF y fuente/revisión; distinguir declaración, observación, inferencia e hipótesis | |
| Evidencia externa | AF/FUE y cobertura: comprador, alternativa o expectativa pertinente | |
| Comparabilidad | Coincidencias y diferencias de población, problema, oferta, tiempo y contexto | |
| Conclusión derivada | AF con premisas, razonamiento y campo de posicionamiento afectado | |
| Expectativas creadas | Alcance, precio, entrega, prueba y condiciones que el marco hace esperar | |
| Esfuerzo de comprensión | Educación, materiales y trabajo necesarios; implicación para K09/K10/K12 | |
| Explicación contraria | Qué otra interpretación encaja y qué evidencia cambiaría la elección | |

## Comparación y recomendación

| Campo | Regla | Valor |
|---|---|---|
| Comparación razonada | Comprensión, relevancia, contraste, fundamento y capacidad; sin promedio que oculte una condición indispensable | |
| Marco recomendado | Elección, motivo frente a alternativas y límites de uso | |
| Afirmaciones utilizables | Qué puede decirse, a quién, con qué evidencia y bajo qué condiciones | |
| Afirmaciones pendientes | Qué se condiciona, reformula o retira y dependencia afectada | |
| Decisión y autoridad | DEC, responsable del compromiso y condiciones; no confundir aceptación con evidencia de preferencia | |
| Consumidores | K08/K09/K10/K15 u otros: campo, revisión, tarea y disposición de recepción | |
| Revisión ante cambios | Premisa que reabre la elección, productor y consumidores; CAM cuando cambie | |

Los mensajes se desarrollan en [mensaje y fundamento](02_mensaje_y_fundamento.md), conservando una misma oferta y sus condiciones.

## Aplicabilidad de los bloques

Antes de emitir K07, completar el núcleo de [N07 Construir posición y mensaje](../../../operacion_conversacional/v0.2/10_primera_pasada.md). Las reglas CONTR, EVAL, USO y de variante de esta plantilla mantienen su momento de exigibilidad. Un bloque condicional se completa cuando afecte al resultado; documentar la condición que lo hace aplicable o su exclusión. Una ausencia material queda localizada y limita el uso dependiente. La cabecera común se registra una vez por artefacto.
